# Auto Clicker (Android)

แอพคลิกอัตโนมัติ ใช้ Accessibility Service (ไม่ต้อง root) รองรับ Android 7.0 ขึ้นไป

## ฟีเจอร์
- แผงควบคุมลอย ▶ เริ่ม / ■ หยุด / ✕ ปิด (ลากที่ ⠿ เพื่อย้าย)
- จุดเป้าหมาย 1–10 จุด ลากวางได้ คลิกเรียงตามหมายเลข
- ตั้งระยะห่างคลิก (มิลลิวินาที) และจำนวนรอบ (0 = ไม่จำกัด)

## สร้างไฟล์ .apk ด้วย GitHub (ทำบนมือถือได้)
1. สร้าง repository ใหม่บน github.com
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
3. ไปที่แท็บ **Actions** → รอ "Build APK" เสร็จ (~3–5 นาที)
4. กดเข้า run นั้น → เลื่อนลงที่ **Artifacts** → ดาวน์โหลด `AutoClicker-apk` (เป็น .zip ข้างในมี `app-debug.apk`)

## สร้างด้วย Android Studio
เปิดโฟลเดอร์นี้ → Build → Build APK(s)
ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## วิธีใช้
1. ติดตั้ง apk (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")
2. เปิดแอพ → กด **1) เปิดสิทธิ์ Accessibility** → เลือก Auto Clicker → เปิด
   - Android 13+: ถ้าเปิดไม่ได้ ให้ไปที่ ตั้งค่า → แอพ → Auto Clicker → ⋮ → "อนุญาตการตั้งค่าที่จำกัด" ก่อน
3. กด **2) แสดงแผงควบคุมลอย** → ลากวงกลมไปจุดที่ต้องการ → กด ▶
